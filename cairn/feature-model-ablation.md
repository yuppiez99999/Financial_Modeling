# 特征集 × 模型族联合消融（Issue #55 第五轮）

**当前真相**：Issue #55 排查的最后一条嫌疑。前四轮（池共线性 / 标签口径 /
周期选择 / 置信度语义）排查完后，剩下两条**从未被量化**的假设：**特征集**
（107 列信息重叠高）与**模型族**（单棵 LightGBM 对日频价量因子的预测力）。
本轮把这两条一起消融，且**换掉了记分板** —— 用 `benchmark_relative` 的
「相对全池等权的净超额」，不再看 IC / 命中率 / AUC。

## 一、可复算命令

```bash
python main.py ablation                                  # 全臂 × 三周期（约 10 分钟）
python main.py ablation --horizons 5                     # 只跑 5 日周期
python main.py ablation --abl-recipes full,compact       # 只跑指定特征配方
python main.py ablation --abl-models lightgbm,extratrees # 只跑指定模型族
python main.py ablation --holding-horizon 10 --cost-level conservative   # 换口径复核
```

`affects_gate=false` / 只读：**不改特征集、不改模型配置、不改权重、不改池、不改门禁**。
落盘 `reports/feature_model_ablation.json`。

数据：`data/raw/` 26 只持仓池真实日K（A股/ETF，2020-01~2026-09，腾讯源，不入库）
+ 真实训练 LightGBM（sklearn 族需 sklearn，已在依赖内）。

## 二、判据（写死，唯一记分板）

- **唯一通过条件 = 组合层「相对全池等权的净超额」**：扣 `2 ×` 单边成本
  （T11.2 定稿三档）、按持有期取**非重叠**调仓日、且必须**优于随机子集**。
  IC / 命中率 / AUC 改善**都不参与判定**（绝对读数无法与市场 beta 分离）。
- **增量 = 净超额 > 0 且相对基线臂的配对 t ≥ 2**（同批样本、同折、同调仓日）。
- **不夸大证据**：候选差异不显著（|t| < 2）→ `inconclusive`；
  只有「净超额 ≤ 0 且 |t| ≥ 2」才允许写 `worse_than_baseline`。
  把"没证明更好"写成"更差"是**夸大证据强度**。
- **多重比较**：一轮比 m 个候选时，写回 Holm-Bonferroni 校正后的 `paired_p_holm`
  （防"跑 20 个臂挑一个 p<0.05"式的自由度回流；试验预算另由 trial_registry 记账）。

## 三、主读数（26 标的真实日K，walk-forward 样本外）

基线臂 = 现行口径（LightGBM + 全量 107 列特征）。逐周期净超额：

| 周期 | 非重叠调仓期数 | 基线净超额/期 | t | 结论 |
|---|---|---|---|---|
| 5d | 325 | −0.292% | −2.12 | `no_edge`（统计上确认跑输等权） |
| 10d | 324 | −0.512% | −2.79 | `no_edge` |
| 20d | 322 | −0.397% | −2.27 | `no_edge` |

**三个周期，现行口径都相对「什么都不做」（全池等权）显著为负。**

### 特征消融（模型族固定 = LightGBM）

| 配方 | 列数 | 5d 净超额 | 10d 净超额 | 20d 净超额 |
|---|---|---|---|---|
| `full`（基线） | 107 | −0.292% | −0.512% | −0.397% |
| `no_duplicate_trend` | 90 | −0.323% | −0.522% | −0.347% |
| `no_ma_family` | 99 | −0.318% | −0.515% | −0.323% |
| `classic_only` | 35 | −0.291% | −0.333% | −0.468% |
| `compact` | 43 | −0.290% | −0.329% | −0.460% |
| `returns_only` | 3 | −0.267% | −0.275% | −0.327% |
| `no_macro` | 92 | −0.297% | −0.338% | −0.429% |
| `no_factor` | 92 | −0.270% | −0.514% | −0.298% |

**没有任何一个子集把净超额推正。** 最好的候选（`no_factor` 5d、`returns_only`
10d/20d）也只是"没那么负"，相对基线臂的配对 t 最大 1.69（Holm 校正后 p ≥ 0.29）。
**IC 与净超额仍然不同向**：`returns_only`（只剩 3 列）在 5d 的 IC 明显更低，
但净超额最高 —— 与上一轮"单周期 IC 排序 ≠ 组合收益排序"同一条教训。

### 模型族消融（特征固定 = 107 列）

| 族 | 5d 净超额 | 10d 净超额 | 20d 净超额 | 相对基线臂配对 t（10d） |
|---|---|---|---|---|
| `lightgbm`（基线） | −0.292% | −0.512% | −0.397% | — |
| `lightgbm_shallow` | −0.259% | −0.496% | −0.408% | +0.17 |
| `lightgbm_uniform` | −0.327% | −0.486% | −0.397% | +1.19 |
| `random_forest` | −0.331% | −0.311% | −0.443% | **+2.58** |
| `extratrees` | **−0.242%** | −0.319% | −0.427% | **+2.16** |
| `logistic_ridge`（线性） | −0.284% | **−0.164%** | −0.342% | **+3.92** |

**唯一的正向读数（如实入库，但不够格改口径）**：
在 **10d** 周期上，`random_forest`（配对 t 2.58, Holm p 0.039）与
`logistic_ridge`（t 3.92, Holm p 0.0004）相对基线族**统计上确认更不差**；
`extratrees` t 2.16 但 Holm p 0.093 不显著。

三点必须同时说清楚：

1. **"更不差"不是"有 edge"**：这几种族的**净超额仍然为负**（−0.31% / −0.16%），
   只是亏得比 107 列 LightGBM 少。**没有一族跑赢等权。**
2. **只在 10d 成立**，5d / 20d 上同方向不显著（`lightgbm_shallow` 5d 的
   t 只有 0.46）。⇒ 是**单周期的孤证**，不是跨周期一致的方向。
3. **线性族也能做到** ⇒ 强烈提示**不是"非线性不够"**，而是现有特征集在
   10d 上对树模型提供了**过多冗余切分空间**（树过拟合噪声），
   降复杂度（浅树 / 线性）反而更稳 —— 与"加更强模型"的直觉相反。

## 四、结论

1. **特征集"加/减"？→ 都不做。** 八个子集无一把净超额推正；最好的候选
   也只是"没那么负"（配对 t 全部 < 2）。**107 列的冗余不是当前瓶颈**。
2. **模型族"换"？→ 不做（但记一条待验线索）。** 5d / 20d 上换族无增量；
   10d 上 `random_forest` / `logistic_ridge` 相对基线"更不差"且过 Holm 校正，
   但**净超额仍为负、且只在单周期成立**。⇒ 够格作为**下一步实验方向**
   （"降模型复杂度 + 限定 10d"），**不够格**改生产配置。
3. **本轮最大的结论不是上面两条，而是记分板**：现行口径（107 列 LightGBM）
   在**三个周期上全部相对等权显著为负**（t = −2.1 ~ −2.8）。
   也就是说：**这套信号目前是"负增量"** —— 按它调仓比直接等权持有更差。
   TrendCast 只读观测 / 风险预警的定位，至此由**独立判据第二次**确认。

## 五、这意味着什么（对下游的建议）

- 下游（tradingview / 28）**不应**把 TrendCast 当作方向性采纳依据 ——
  这不只是"区分度弱"（AUC 0.50~0.54），而是**相对等权为负**；
- 值得保留的是**观测/风险预警**用途：置信度是波动率探测器
  （见 `cairn/regime-conditioned-signal.md`），可用于"当前波动状态"读数；
- 若要把"风险预警"做成真产品，应该**另外立项**做"波动/回撤预警"，
  而不是在方向预测上继续加特征或换模型（本轮已证两条都不解决问题）。

## 六、踩坑与解法（contains）

- **contains 记分板必须在比较前写死**：本轮再次复现"IC 与净超额不同向"
  （3 列的 `returns_only` IC 更低但净超额最高；10d 上线性族 IC 未必最高但净超额最好）。
  凡是用 IC / 命中率排序做技术选型，结论都不可信。
- **contains 自研模型的入口不叫 `fit`**：`LightGBMModel.train()` 是唯一训练入口，
  且内部自带 `StandardScaler`。若适配层按 sklearn 惯例调 `fit()`，会抛
  `AttributeError` —— 而消融模块的设计是"单臂失败即标 `available=false`"，
  于是**所有 lightgbm 臂静默变成"样本不足"**，报告看起来"跑完了但没数据"。
  已修（`_LgbmAdapter`），并加守卫 `test_lightgbm_adapter_uses_train_not_fit`。
- **contains 分组匹配用 `in` 会整族错位**：`ma_` 用子串匹配会吞掉
  `ema_10` / `dema_5` / `wma_10` / `trima_5`（趋势族整族被划进均线族），
  消融读数随即失去意义。已改为**前缀族优先 + 包含族兜底**的两段匹配，
  并守卫 `test_ma_prefix_does_not_swallow_ema_family`。
- **contains 特征列必须"全覆盖或显式披露"**：分组规则漏掉的新列**不会**进任何
  子集，读数看起来正常实际上少测了。模块对未覆盖列 fail-loud 告警并写入
  `uncovered_columns`（当前全池 107 列 100% 覆盖）。
- **contains 臂间必须同批样本同折**：若每臂各自调一次 `walk_forward_splits`，
  一旦某臂样本数变化（新特征引入 NaN）折边界就漂移，臂间差值失去意义。
  模块在 `build_panel` 里**预生成折索引**，所有臂共享。
- **contains 消融臂不要落盘生产模型**：`LightGBMModel.__init__` 会
  `mkdir(save_dir)`，按默认 `models/` 会让每跑一次都触碰线上产物目录。
  模块把消融臂产物定向到 `reports/_ablation_models`。
- **contains 随机子集对照要同规模同种子**：候选臂共用基线臂的随机对照
  （同一批调仓日 + 同一子集规模 + 同 seed），否则"是否优于随机"不可比。
- **contains 数据分段拉取会在除权日缺行**：`data/raw` 的日K按**查询窗口**
  分段采集，除权日会让某些标的在某天缺行。严格按日期 inner join 会白丢
  大量调仓日（5d 周期从 325 掉到 184）；模块在**只回看、不允许回看未来**的
  前提下把信号日归并到最近的可用价格日（`max_lag_days`，默认 5）。
  与 `edge-check` 的 184 期差异即来自此 —— 两者**同判据、同池**，只是网格更密。

## 七、边界声明

- 只报数，`affects_gate=false`，不据自动改特征集 / 模型配置 / 权重 / 池 / 门禁；
- 成本只计信号臂（基准 = 全池等权 buy&hold，无换手成本）；
- 粗网格与 `edge-check` 的细网格**同判据、同池、同成本档**，结论方向一致，
  不跨网格横向比较绝对读数；
- 锚点/调仓期之间有重叠（不同持有期之间），故**不跨持有期比较绝对值**；
- 多重比较用正态近似 + Holm（自研，零新依赖）；结论是"不显著/为负"，
  校正只会更保守；
- `data/raw/` 为本地缓存（不入库），复算需重新采集（A股/ETF 走腾讯源）。
