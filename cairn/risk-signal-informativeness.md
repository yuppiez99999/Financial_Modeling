# 风险预测力检验（Issue #55 —— "风险预警"这条退路到底成不成立）

**当前真相**：Issue #55 八轮排查（池 / 标签 / 周期 / 置信度语义 / 基准相对净超额 /
特征集 × 模型族 / 状态分层）**全部有读数、全部为负**，方向预测这条线**到顶**。
历轮一致建议「另立项目做波动 / 回撤预警」。本轮**不预设它成立**，
而是把那条建议的**唯一地基**单独拿出来做独立检验。

可复算命令：

```bash
python main.py risk-signal                          # → reports/risk_signal.json
python main.py risk-signal --horizons 10            # 只跑 mid 周期
python main.py risk-signal --stability-subsets 0    # 跳过子池稳健性
```

只读：`affects_gate=false`；**不改门禁 / 权重 / 池 / 配置**。本模块只回答
「值不值得立项」，**不**回答「新口径长什么样」。

## 一、为什么要先查这条

「另立项目做风险预警」的全部依据是一个**连带结论**：

> 「置信度 = 波动率探测器」⇒ 模型输出可作风险 / 波动预警。

而这个地基在项目文档里是**自相矛盾**的：

- `regime-conditioned-signal` 实测 `IC(置信度, 波动)` 在 **5 只小池**上 +0.10~+0.34，
  在 **26 只池**上**接近 0**；
- 同一份文档的结论段却写成「置信度是波动率探测器」。

**池是实验条件的一部分**，小池强读数不能当大池结论 —— 这正是该文档自己写下的坑。
⇒ 不先验地相信它，也不把"建议"当"结论"。

## 二、判据（写死，防自由度回流）

方向预测那轮最贵的错误是**判据错位**（IC / 命中率 / 绝对收益 → 换判据后结论直接相反）。
本模块沿用同一纪律：

1. **必须有基准对照**：风险预测的"什么都不做"对照 = 用截至 t 的**已实现波动率直接外推**
   （trailing vol）。波动有长记忆，这是朴素但很强的基线。模型输出必须**在它之上**提供增量。
2. **无前视**：风险标签只用 `(t, t+h]`；trailing 基线只用 `[.., t]`（有守卫）。
3. **增量判据 = 正交化后的偏秩相关**：信号与对照都对 trailing vol 的秩做残差化，
   再看信号残差与未来风险的相关 —— 量到的才是**超出朴素基线的增量**。
4. **重叠校正**：未来 h 日标签在相邻日重叠，名义 n 会把 t 虚高约 √h 倍 ⇒
   t 用**有效样本数** `n_eff ≈ n/h` 算。
5. **效应量下限**：仅"显著"不够 —— 须 |partial IC| ≥ **0.10**，防大 n 把 0.03 的小相关抬成"显著"。
6. **子池稳健性**：池层面抽样，成功率如实输出，分级 `robust` / `suggestive` / `fragile`。
7. **不把"没证明"写成"证明"**：无增量如实判 `no_risk_increment`。

方向：`conf → 未来波动` 需 **正**；`conf → 未来回撤` 需 **负**（回撤是负值，越深越负）。

## 三、主读数（26 标的真实日K，walk-forward 样本外，base 口径）

| 周期 | n | 有效 n | 朴素基线 IC(trail→未来波动) | 原始 conf→波动 | 原始 conf→回撤 | **偏相关 conf→波动** | 偏相关 conf→回撤 |
|---|---|---|---|---|---|---|---|
| 5d | 12376 | 2475 | **0.694** | 0.087 | −0.056 | 0.057（t 1.74） | −0.035 |
| 10d | 12298 | 1229 | **0.742** | 0.105 | −0.083 | 0.049（t 1.72） | −0.053（t −1.85） |
| 20d | 12142 | 607 | **0.751** | −0.110 | −0.024 | 0.067（t 1.66） | −0.088（t −2.17） |

- **朴素 trailing-vol 基线极强**（对未来波动 IC 0.69~0.75）—— 波动预测本来就"好做"；
- 模型输出的**增量**偏相关只有 **0.03~0.09**，**三周期全部低于 0.10 效应量下限**，
  且重叠校正后 |t| 全在 2 附近或以下；
- ⇒ 三周期一致：`no_increment_naive_wins`。

## 四、子池稳健性（12 次抽 18 只）

`n_holds = 2 / 12`，`hold_rate = 0.167`，`robustness_verdict = **fragile**`。
⇒ 即便放宽到"只看方向 + 显著"，增量在子池上**也不稳**。

## 五、结论

```json
{"conclusion": "no_risk_increment",
 "recommendation": "模型输出不提供超出朴素 trailing-vol 的风险增量 ⇒ 若要做波动/回撤预警，用朴素基线即可，不必为本模型的输出立项。"}
```

**"另立项目做风险预警"这条退路，地基不成立**：

- 不是"模型输出没用"，而是**朴素 trailing-vol 已经把它能做的做完了**；
- 置信度里那点残差波动信息（偏 IC ~0.05）**小于效应量下限、且子池不稳**；
- ⇒ 真要做风险预警，**用朴素波动基线**，**不必**为本模型的输出立项 ——
  更不必为一个"建立在小池强读数上、且大池被稀释"的连带结论投入工程。

## 六、边界声明

- 只报数，`affects_gate=false`，不据自动改权重 / 门槛 / 池 / 配置；
- 数据 26 只 A股/ETF 真实日K（腾讯源，`data/raw/` 不入库），窗口约 2023-06~2026-09（各 800 根）；
- 回撤标签用"未来区间最低 / 起点 − 1"近似（只用于**秩相关**，不用于绝对量级读数）；
- t 已按重叠折算有效 n；若结论是"不显著/为负"，多重比较校正只会更保守，不影响方向；
- 本模块**不**声称"风险预警一定做不了"——只声称"**本模型的输出**不足以支撑它"。

## 七、踩坑与解法（contains）

- **contains 连带结论最容易变成"建议的论据"**：历轮把"置信度=波动率探测器"
  当作已证事实去建议立项，实则它来自小池强读数、大池被稀释、且从没独立检验过。
  **建议的论据必须先验证**，不能拿"上次的建议"当"这次的证据"。
- **contains 大 n 会把微小相关抬成显著**：偏 IC 0.049 在名义 n=12298 下 t≈5.4（"显著"），
  但折算有效 n=1229 后 t≈1.7，且效应量远低于 0.10 下限。
  **只报 p 不报效应量 = 用样本量买结论。**
- **contains 重叠样本是波动/回撤研究的默认陷阱**：未来 h 日标签逐日重叠，
  名义 n 高估自由度约 h 倍。本模块用 `n_eff ≈ n/h` 折算（保守），
  与 `benchmark_relative` 的"非重叠调仓日"同一纪律。
- **contains 朴素基线必须给足**：波动有长记忆，trailing vol 是强基线。
  若只跟"随机/常数"比，任何模型都能"显著更好" —— 那是自欺。
  对照要选**该任务上最强的朴素方法**。
- **contains 结构化避开 `_fwd_ret` 泄漏坑**：本模块的风险数据集**只吃价格表**
  （`close`），从结构上不碰特征列（含 `_fwd_ret`，与 target 秩相关 0.72）。
