# 基准相对决策增量（Issue #55 —— 信号到底有没有跑赢"什么都不做"）

**当前真相**：Issue #55「选择最优方案」的裁定依据。前三轮
（①池共线性 → ②标签口径 → ③周期权重 / 波动分层置信度，见
`model-optimization-findings.md` / `regime-conditioned-signal.md`）把候选方向
逐个排查完，但都停在**绝对读数**上。本轮补上缺失的那一问，并据此**否掉**了
遗留的口径变更候选。

可复算命令：

```bash
python main.py edge-check                                # → reports/benchmark_relative.json
python main.py edge-check --holding-horizon 10           # 换持有期复核
python main.py edge-check --cost-level conservative      # 换成本档复核
```

只读：`affects_gate=false`；**不改门禁 / 权重 / 池 / 配置**。

## 一、为什么必须换判据

前几轮的判据都是「信号自身样本内」的绝对读数：IC、命中率、平均已实现收益、
置信度分档、波动分层。它们有一个共同的盲点 —— **没有对照**。

26 标的池（A股/ETF）在 2021-05~2026-09 的**全池等权 buy&hold**
年化 **+19.1%**（r=0.00403/期、夏普 0.83，无换手成本）。
也就是说：任何「平均已实现收益为正」「IC 为正」「命中率 >0.5」的读数，
**都可能只是市场 beta**，完全不能说明这套信号在提供决策增量。

⇒ 本轮判据写死为：**相对全池等权的净超额**（扣成本），且必须**优于随机子集**。

## 二、主读数（26 标的，真实日K + 真实训练 LightGBM，walk-forward 样本外）

非重叠调仓、`2 × 单边成本`（base 档 0.00075）：

| 持有期 | 信号年化 | 基准年化 | 净超额/期 | t | verdict |
|---|---|---|---|---|---|
| 5d | +23.9% | +19.1% | **−0.070%** | −0.84 | `no_edge` |
| 10d | +24.0% | +18.8% | +0.029% | +0.18 | `inconclusive` |
| 20d | +24.8% | +19.3% | +0.225% | +0.66 | `inconclusive` |

**信号年化看起来"跑赢"基准，但扣掉成本与超额 t 检验后就站不住了**：

- 5d：净超额**为负** ⇒ 不如直接等权持有；
- 10d/20d：净超额为正但 **t = 0.18 / 0.66**（远不到 2），且调仓期数只有 126 / 63。

## 三、随机子集对照（这条把"看着跑赢"彻底解掉）

每次抽**同样数量**（16 只）的随机标子集，跑 40 次：

| 持有期 | 随机子集净超额均值 | 信号净超额 | ≤信号的随机次占比 |
|---|---|---|---|
| 5d | −0.141% | −0.070% | **7.5%** |
| 10d | — | +0.029% | 7.5% |
| 20d | — | +0.225% | 5.0% |

**随机抽 16 只就能达到、甚至超过信号的表现** —— 说明"选中这些标的"
本身没有信息含量。信号不是选标的选得好，是**满仓参与**了。

## 四、周期权重重排：**被否，不做**

用**同一个**基准相对判据比候选权重（h=5）：

| 候选权重 | 年化 | 净超额/期 | t |
|---|---|---|---|
| 现行 `0.30/0.35/0.35` | +23.89% | −0.070% | −0.84 |
| 等权 `1/3` | +24.09% | −0.067% | −0.82 |
| 纯 5d `1/0/0` | +22.90% | −0.090% | −0.93 |
| 纯 10d `0/1/0` | +22.90% | −0.074% | −0.90 |
| 纯 20d `0/0/1` | +22.60% | −0.091% | −1.18 |

**五个候选没有一个净超额为正**，差异全在噪声内（t 都在 ±1.2 内）。
⇒ 周期权重重排**不做**。前一轮「按单周期 IC 重排」的建议到此**双重证伪**：
第一轮用组合层已实现收益证伪（IC 排序 ≠ 收益排序），本轮用基准相对判据再证伪
（连现行权重本身都没有相对基准的增量）。

## 五、结论（三个决策问题一起回答）

1. **周期权重按证据重排？→ 不做。** 候选权重无一带净超额，差异在噪声内；
   在"连现行口径都没跑赢等权"的前提下，重排只是把一个不赚钱的信号重新加权。
2. **把「置信度与波动状态联读」纳入采纳口径？→ 暂不。** 上一轮自评级
   `suggestive`（子池 7/12），且本轮基准相对判据否掉了整条信号线的增量 ——
   在一个没有 edge 的信号上调整采纳口径，不改变结论。
3. **下一步方向 → 换问题，不是换参数。** 池 / 标签 / 周期 / 交付形态 / 采纳口径
   全部排查完毕，五条假设里四条证伪。**剩下的最大嫌疑是模型本身没有 edge**
   （日频价量因子对 A 股 ETF 池的预测力，可能已被市场消化）。
   建议下一轮做**特征集 × 模型族的联合消融**，并以**本判据**（相对等权的净超额）
   作为唯一记分板 —— 不再看 IC / 命中率。

## 六、踩坑与解法（contains）

- **contains 判据错位是这类项目最贵的错误**：前几轮用 IC / 命中率 / 绝对收益
  排序，本轮用「相对等权的净超额」排序，**结论直接相反**（前几轮认为 5d 最强、
  20d 组合收益最差；本轮看净超额，5d 最差、20d 最好，且全部不显著）。
  记分板选错，任何结论都是假的。**判据必须在被比较之前就写死。**
- **contains 绝对收益为正 ≠ 有 edge**：26 标的池 2021-05~2026-09 等权买入持有
  年化 +19.1%；信号年化 +23.9% 看着更高，但扣成本后净超额为负、且随机子集可达。
  **没有基准就没有结论。**
- **contains 重叠样本会伪造显著性**：按持有期取非重叠调仓日（`grid[::h]`）。
  若每天调仓而持有 h 日，相邻样本共享 h−1 日的收益，t 值会被虚高约 √h 倍。
- **contains 快速验证时最容易漏掉 `_` 前缀列**：`scripts/evaluate_models` 与
  `src/eval/*` 都显式过滤 `_symbol` / `_fwd_ret`（后者是**未来收益**，
  与 target 的秩相关高达 0.72）。手写快速脚本若不照抄这个过滤，会得到
  p 饱和在 0.02/0.98、命中率 100% 的假读数。本模块的 `_horizon_returns`
  只吃价格表，不碰特征列，从结构上避开这个坑。

## 七、边界声明

- 只报数，`affects_gate=false`，不据自动改权重 / 门槛 / 池 / 配置；
- 成本只计信号臂（基准=等权 buy&hold 无换手）；保守档复核结论不变；
- 锚点/调仓期之间有重叠可能（不同持有期之间），故**跨持有期不做横向比较**，
  只在同一持有期内比候选；
- 调仓期数 63~252，t 检验为**朴素**口径（未做多重比较校正）——
  但本轮结论是"不显著/为负"，校正只会让结论更保守，不影响方向；
- `data/raw/` 为本地缓存（不入库），复算需重新采集（A股/ETF 走腾讯源）。

## 八、状态分层的净超额（Issue #55 第七轮：增量是不是只在某个市场状态下）

**问题**：前六轮把池 / 标签 / 周期 / 置信度语义 / 特征集 / 模型族全部排完，
结论都是"相对等权显著为负"。但六轮全是**全样本平均**读数 —— 有一个**从未被
独立检验**的残留可能：信号**大部分时间没用**，只在某种市场状态下才有增量，
被平均掉。S18 的 HMM 三态与上一轮"高置信 × 高波动"线索都指向这个方向。

**命令**（默认开启，与全局判据同源）：

```bash
python main.py edge-check                                  # 附状态分层净超额
python main.py edge-check --no-regime-breakdown            # 关闭（只看全局）
python main.py edge-check --regime-refit-every 10 --regime-window 20
```

**口径**（写死，防自由度回流）：

- 状态由**全池等权市场层**拟合（与 `python main.py regime` 同观测源），
  首选 HMM `expanding` 口径（无前视）；hmmlearn 缺失 / 拟合退化时**如实降级**
  为规则口径（同样无前视），`mode` 字段标 `rules_fallback`，**不冒充 HMM**；
- 调仓日状态取**当日**标签（标签只由 ≤ 当日的观测拟合 → 无前视，
  有回归守卫：截断 t 之后的观测，t 及更早标签不变）；
- 逐期净超额 `(signal − benchmark) − 2×单边成本`，按状态分组 —— 与全局判据
  **逐式同源**，不做任何状态专属的成本 / 门槛调整；
- 单状态调仓期数 < `MIN_REGIME_PERIODS`（8）→ 该状态 `available=False` + reason，
  **不外推该状态结论**；可比状态 < 2 → 整个分层 `available=False`；
- **只有**某状态净超额 > 0 **且** `t ≥ 2` 才置 `conditional_edge_hint=True` ——
  状态间"最高减最低"的极差（`spread`）单独给出，但**不单独作为 edge 依据**
  （极差可能来自噪声，必须配 t）。

**主读数（8 标的真实日K，2020-01~2026-09，walk-forward 样本外，base 成本档）**：

| 项 | 读数 |
|---|---|
| 全局净超额/期 | −0.214% |
| 全局 verdict | `no_edge` |
| 状态口径 | `hmm_expanding`（无前视），835 日中 697 日有标签 |
| bull | 期数 0（该窗内 HMM 未产出 bull 状态）→ `available=False`，**不外推** |
| range | 期数 66，净超额 −0.299%（t −1.91），**为负** |
| bear | 期数 28，净超额 −0.013%（t −0.07），**为负** |
| `conditional_edge_hint` | **False** |
| `conclusion` | `no_conditional_edge` |

⇒ **没有一个状态的净超额为正**，"增量只藏在某个市场状态里"这一残留假设
在本判据下**不被支持**。这是第六轮结论之后的又一次独立复核：不是"平均没用"，
而是**各状态下都没用**（range 甚至显著为负）。注意 bull 当期无有效样本，
如实标不可用、**不外推**。

**如实说明边界**：8 标的冒烟、单窗、分状态后每格期数偏少（28~66），故
`spread` 的 0.286% 极差**不足以**支撑任何条件 edge 主张 —— 它只被记为待观察量，
不构成口径变更依据。全池 38 标的分状态读数待跑（与"38 池模型信号完整回测"同一批待办）。

## 九、踩坑与解法（续，contains）

- **contains 平均会掩盖状态条件性**：全样本"净超额为负"不必等价于"每个状态都为负"。
  本轮把它拆开独立检验，结论是"确实每个状态都为负"——**但这是检验出来的，
  不是假设出来的**；若某状态转正且 t ≥ 2，就必须如实报告，不能被全局均值埋掉。
- **contains 状态标签必须无前视**：直接把全样本 decode 的状态拿来分层，
  等于用未来信息给当期分组（`lookahead_prefixed=True` 只许作对照，不得作证据）。
  本模块只用 `regime_labels` 的 expanding 口径，并有截断回归守卫。
- **contains 状态口径要如实标注降级**：缺 hmmlearn 时不能"假装跑过 HMM"。
  降级到规则口径必须写进 `mode`，让读者知道读数来自哪个口径。
