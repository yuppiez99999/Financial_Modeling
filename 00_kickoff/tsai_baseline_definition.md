# tsai baseline 任务补充定义

本文件补充 T2.3 和 T2.4 的执行标准，避免光有任务编号却不知道怎么验收。

## T2.3: tsai baseline 跑通

目标：
- 在当前环境中，用最小数据集跑通一个 tsai 风格的预测 baseline
- 得到可复现的训练/验证指标

验收标准：
- 最小脚本存在且可运行
- 训练过程不报致命错误
- 输出基本分类指标
- 指标计算方式与 T2.1 定义一致

容忍：
- 第一版不要求高性能
- 不要求大规模数据
- 允许用示例数据先验证流水线

## T2.4: 预测 baseline 对比

目标：
- 把 baseline 结果和事先约定的简单基准进行对比
- 记录优劣和原因

基准约定（初版）：
- 简单方向预测基准
- 至少包含 dumb 基准，例如恒定预测、 Majority class 预测、最近窗口占优预测

对比内容：
- 分类指标对比
- 回测视角结果对比（如有）
- 是否优于 dumb 基准
- 是否存在明显过拟合迹象

记录要求：
- 每次对比结果要留痕
- 基准选择理由要写明
- 不达标时要标记为待优化

## 自动化程度

- T2.3/T2.4 初期以人工检查+最小脚本跑通为主
- 后续可逐步自动化，但当前阶段不强求全自动
