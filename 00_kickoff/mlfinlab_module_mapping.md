# 模块挑选与映射

本文件记录 mlfinlab 金融建模辅助阶段的模块挑选逻辑与映射方式。

## 挑选原则

- 优先选择与当前回测/预测流水线强相关的模块
- 不引入与项目目标无关的复杂功能
- 先选可独立验证的小模块
- 依赖和环境成本要可接受

## 候选关注点

- 特征构造相关思路
- 标签/目标构造相关思路
- 滑窗划分与时间顺序处理
- 泄露防范与验证组织方式
- 组合优化相关概念（如后续需要）

## 映射方式

1. 先将感兴趣的模块列入候选清单
2. 对每个候选写一行映射说明：
   - 它解决什么问题
   - 与当前项目的接口在哪里
   - 是否独立可验证
3. 优先落地能直接产出文档、脚本或检查项的候选
4. 不确定项标记为待验证，不强行入库

## 映射记录格式

- 模块/概念名称：
- 来源/参考：
- 映射到本项目哪个环节：
- 当前状态：候选 / 验证中 / 已接入 / 暂不接入
- 备注：

## 初版结论

- 本阶段以挑选和映射为主，不强求完整接入
- 映射结果要能指导后续验证与整合
