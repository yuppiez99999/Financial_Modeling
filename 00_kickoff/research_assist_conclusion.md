## 一、为什么这一档「功能最少、纪律最重」

投研辅助（基本面 / 事件 / 情绪的中文研报式解读）是**另一个信息维度**，
但它有两个硬风险：

1. **依赖重**：LLM 调用需要网络 + 成本 + 不可复现（CI 离线跑不了）；
2. **噪声大**：LLM 结论若无法量化，接进信号路径等于**给门禁注入随机性**。

排期里就已写明：**只读、不进信号路径、评估不通过则整阶段取消。**
「不引入」也是有效交付 —— 这比强行接入更负责。

## 二、方法（离线优先 / 不可量化即止损）

- **候选调研**（T20.1）：3 个候选按「A 股适配 + 离线可复现 + 许可证明确」三项准入逐一评估；
- **只读附注**（T20.2）：LLM 结论只作报告附注（`research_note`），
  类型上与 probability / direction / signal **不连通**；
- **离线对照**（T20.3）：同一批样本「有/无附注」的命中率差异 ——
  附注不参与打分，故差异**在结构上必然为 0**；如实记 `unverifiable` 并**止损**；
- **保留决策**（T20.4）：决策单，无 `decided_by` 时最多 `cancel` / `defer`。

复现命令：

```bash
python main.py research-assist          # 调研 + 只读附注 + 离线对照 + 决策单
```

落盘：`reports/research_assist_evaluation.json` / `_contrast.json` / `_decision.json`。

## 四、保留决策（T20.4）

**要你定什么**：这条链路**保留与否**（含成本与噪声风险）；不保留则**整阶段取消**。

**现状默认**：`cancel` / `pending` —— 无人工签字不放行。

理由（决策单 `blockers`）：

1. 无候选满足准入条件（A 股适配 + 离线可复现 + 许可证明确）；
2. 离线对照**结构性不可量化**（附注不参与打分）→ 效果无法验证，已止损；
3. 缺少人工签字（`decided_by`）。

**签 / 不签的后果**

- **不签（即维持默认 cancel）**：H5 整阶段取消，只保留**调研结论**作为知识资产；
  零新增依赖、零新增维护面；
- **签「保留」**：也不是放它进信号路径 —— 附注永远只挂报告层。
  代价是需要额外维护 LLM 调用链（网络/成本/不可复现），
  且**无法证明它带来增量**（对照结构性不可量化）。若你要保留，
  建议限定为**离线人工工具**而非仓库链路。

**若日后要改用本地模型复现**：需先解决「可离线复现」这一准入项，
届时按新候选重新走一遍 T20.1 流程（本结论只对上述 3 个候选有效期）。
