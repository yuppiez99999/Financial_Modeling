# 泄露检查清单

本清单用于核对预测任务和回测是否存在未来信息泄露。

使用方式：
- 任意模型或回测方案落地后，逐项检查
- 未通过项必须记录并修复，不得跳过

## 标签相关

- [ ] 标签构造是否用了未来收益
- [ ] 标签窗口起止是否与预测时点一致
- [ ] 是否在标签定义中引用了预测样本之后才可得的信息

## 特征相关

- [ ] 特征是否只使用了当时可观测的信息
- [ ] 是否在滑动窗口计算中使用了当前时刻之后的数据
- [ ] 标准化/归一化是否用了未来样本的信息
- [ ] 缺失值处理是否只依赖过去信息

## 划分相关

- [ ] 训练/验证/测试是否按时间顺序划分
- [ ] 是否存在样本穿越
- [ ] 回测起止时间是否与评价样本一致

## 评价相关

- [ ] 评价指标是否反映真实可执行表现
- [ ] 是否只在样本内表现好就宣称有效
- [ ] 结果是否对参数敏感，是否做过稳健性检查

## 成交/成本相关

- [ ] 回测中是否插入了不合理的成交假设
- [ ] 滑点/佣金是否足够保守
- [ ] 信号到成交之间的延迟是否合理
