# 小范围试跑定义

本文件定义 mlfinlab 阶段的小范围试跑 표준。

## 目的

- 在小样本/小功能范围内验证可行性
- 避免一上来就做大规模实验
- 留下可复用的最小验证记录

## 试跑范围

- 数据规模：尽量用小数据集或示例数据
- 功能范围：只涉及当前关心的最小环节
- 运行时间：应在合理范围内快速完成
- 依赖范围：尽量少引入新依赖，若引入则单独记录

## 试跑内容

1. 准备最小输入数据
2. 运行最小流程脚本
3. 检查是否报致命错误
4. 记录核心输出与结论

## 验收标准

- 最小脚本可运行
- 至少产生可读输出或结果文件
- 关键环节没有硬性阻塞
- 若未通过，记录原因与下一步

## 记录方式

- 使用数据/样本范围：
- 运行脚本/入口：
- 结果摘要：
- 是否通过：
- 未通过 cause：
- 下一步：
