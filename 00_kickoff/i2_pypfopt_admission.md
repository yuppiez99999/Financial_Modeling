# T22.3 · PyPortfolioOpt 准入评估（S22 / I2 可选优化臂）

> Issue #54 · 2026-09-13 ｜ 结论：**不引入运行时，优化臂取消**
> （依据候选矩阵第四节第 3 条「零重型依赖」与 H5 先例「准入不过则取消该臂」）

## 一、候选画像（GitHub 网页核验，2026-09-13）

| 项 | 事实 |
|------|------|
| 仓库 | `robertmartin8/PyPortfolioOpt` |
| star / 许可证 | 6k / MIT（许可证本身无障碍） |
| 功能 | 均值-方差有效前沿、max Sharpe、min vol、Black-Litterman、HRP 等 |
| 关键依赖 | **cvxpy**（凸优化求解器）+ numpy/pandas/scikit-learn |
| 运行环境 | 本项目运行时 **Python 3.8**；cvxpy 需随附求解器（ECOS/OSQP/SCS 二进制） |

## 二、准入判定（三项全过才引入）

| 准入项 | 判定 | 依据 |
|------|------|------|
| 依赖代价 | ❌ | cvxpy + 求解器二进制链路，违背「零重型依赖、CI 离线可跑」；本项目 T22.2 实测三臂对照（等权/1-ATR/置信度）**无需求解器**——权重都是闭式归一，优化器没有非它不可的环节 |
| py3.8 兼容 | ⚠️ | cvxpy 旧版本可装，但「能装」不等于「值得装」；依赖项 1 已否决 |
| 许可证 | ✅ | MIT，无传染性问题 |

**结论：0 项否决不可行 → 依赖代价一票否决 → 优化臂取消。**

## 三、不取消的理由是否存在过？（自我质询）

- 若三臂对照显示等权/1-ATR/置信度臂**相互无差异**，优化器可能提供增量
  —— 实测（`reports/portfolio/portfolio_backtest.json` weights_ab）：1-ATR 臂
  在三档成本下收益/夏普/回撤**全面优于等权**（base 档 0.6905 vs 0.6116），
  置信度臂退化为等权。优化器的典型卖点（协方差结构利用）在 3 标的冒烟里
  无法验证，但「先引入求解器再验证」顺序颠倒 —— 正确顺序是：模型信号接入
  全池后，若加权臂间仍有未解释差异，再评估求解器（届时也先看 skfolio 的
  维护态与 py 版本要求，本项目 py3.8 升级与否属另一独立决策）。
- 结论维持取消；本文件作为「为什么没有引入」的证据链存档。

  不得声称已引入运行时）；
