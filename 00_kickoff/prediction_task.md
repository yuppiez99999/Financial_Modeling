# 预测任务定义

本文件定义 tsai baseline 阶段要解决的预测任务。

目的：
- 明确预测目标
- 明确标签构造方式
- 明确特征窗口和标签窗口
- 为后续模型对比提供统一基准

## 任务编号

- 任务ID: T2.1
- 名称: 预测任务定义
- 所属阶段: tsai 预测 baseline

## 预测目标（初版）

第一版以最基础的方向预测为主：
- 目标类别：涨 / 跌 / 持平
- 预测粒度：日级别方向
- 目标使用：后续回测信号的输入之一

## 标签构造

- 使用未来 N 日收益作为标签依据
- N 日收益 > 正阈值 -> 上涨标签
- N 日收益 < 负阈值 -> 下跌标签
- 否则 -> 持平/中性标签
- 阈值要根据资产特性和频率确定，后续再精调

## 特征窗口

- 特征使用过去 M 期的可观测信息
- M 需要小于标签窗口，防止泄露
- 特征来源暂定为价格衍生特征 + 已有宏观/表达式特征

## 时间划分

- 按时间顺序划分训练/验证/测试
- 不得随机打散
- 验证集用于选择模型/超参
- 测试集仅用于最后评价

## 评价方式

- 分类任务：准确率、精确率/召回率、F1、方向一致率
- 同时记录回测视角的结果，不只看纯分类指标
- 评价要兼顾样本内和样本外表现

## 注意事项

- 未来信息泄露是最大禁区
- 标签构造要足够简单，先跑通再优化
- 任务定义变更时要记录原因
