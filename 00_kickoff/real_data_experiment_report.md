# 真实数据实验报告

本文件记录基于 AKShare 真实数据的实验结果。

## 数据源

- 数据源：AKShare (v1.18.41)
- 标的：沪深300 指数 (sh000300)
- 数据范围：约 5990 个交易日（截至 2026-09-10）
- 缓存机制：本地 Parquet 缓存，24 小时过期

## 实验 1：简单 MA20 回测（近 252 个交易日）

| 指标 | 值 |
|------|-----|
| 累计收益率 | -11.75% |
| 年化收益率 | -11.79% |
| 最大回撤 | -14.44% |
| 盈利期比例 | 23.5% |
| 持仓期数 | 124 / 252 |

## 实验 2：Baseline 对比（近 252 个交易日）

| 策略 | 累计收益 | 年化收益 | 最大回撤 | 盈利期比例 |
|------|---------|---------|---------|-----------|
| 恒定做多 | +1.90% | +1.90% | -10.49% | 51.4% |
| 恒定空仓 | 0% | 0% | 0% | 0% |
| 最近方向 | -13.57% | -13.62% | -14.94% | 19.9% |
| MA5/MA20 金叉 | -7.78% | -7.81% | -12.32% | 25.9% |

**最优 baseline：恒定做多 (+1.90%)**

## 结论

1. 在观察期内，简单趋势策略（MA 交叉）表现不佳
2. 恒定做多反而表现最好，说明该区间整体略有上涨但波动大
3. 最近方向策略表现最差，说明短期反转效应不明显
4. 后续需引入更复杂的信号和风控机制
